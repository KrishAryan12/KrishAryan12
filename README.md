### ◆ Featured work

**TraceLens** · production, private\
Autonomous root-cause agent: a native ReAct loop on GPT-4o, no agent frameworks, 40+ tools across 12+ sources, ranked confidence-scored hypotheses, then a Jira ticket and a Slack summary. It learns from each incident in a knowledge graph on Apache AGE. 1,094 tests. [Case study](https://krisharyan.vercel.app/work)\
*Python · FastAPI · Azure OpenAI · Apache AGE · React · AWS EKS*

**LogAgent** · production, private\
A ReAct agent with read-only bash on the log server, reading 200k–30M lines per service per day. No ingestion pipeline, no vector DB. Used by the SRE team.\
*ReAct · Bash · AWS SSM*

**Teardown** · live\
Paste a URL, get a fix list an AI coding agent can execute. [Live](https://teardown-lab.vercel.app) · [Repo](https://github.com/KrishAryan12/Teardown)\
*Next.js · React · Chromium · axe-core*

**Stockroom** · live\
Orders that survive concurrency: row-locked transactions, idempotent creation, audit logs. [Live](https://stockroom-fv47.onrender.com/) · [Repo](https://github.com/KrishAryan12/stockroom)\
*FastAPI · React · PostgreSQL · Docker*

Also in production: AlertFlow, which folds alert storms into one triage queue across 185+ services, and an in-house Sentry replacement.
