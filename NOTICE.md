## Fonts (SIL Open Font License 1.1)

- **Oxanium** by Severin Meyer, via the `@fontsource/oxanium` package. Used as outlined glyph paths

No font files are committed; glyph outlines are generated at build time.

## Logos

- **Simple Icons** (CC0 1.0, https://simpleicons.org), via the `simple-icons` package. Every mark in
  `assets/logos/` and in the stack and credential panels comes from Simple Icons and is recoloured
  to the house cyan. `assets/logos/manifest.json` lists each mark and where it is used.
- Brands without a Simple Icons mark (AWS, AWS EKS, DynamoDB, Amazon Bedrock, Azure OpenAI /
  GPT-4o, DeepLearning.AI) appear as plain text chips (for example "AWS", "EKS", "4o", "DL"). These
  are typographic labels, not the vendors' logos.
- Logos indicate technologies the owner uses or issuers of courses the owner completed. They imply
  no endorsement, partnership or affiliation. The owner's employer's logo is not used.

## Inspiration

The neon-grid visual language is inspired by a film the owner watches too often. It uses no film
logo, typeface, stills or props, and is not affiliated with or endorsed by the film or its studio.

## Telemetry

The live telemetry panels are generated by this repository's own GitHub Action from the GitHub
API and the owner's own Teardown deployment. No third-party rendering service, counter or tracking
pixel is used.
